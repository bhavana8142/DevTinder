# API LiST

## AUTH ROUTER

    - POST/signin
    - POST/login
    - POST/logout

## PROFILE ROUTER

    - PATCH/profile/edit
    - PATCH/profile/password

## CONNECTIONS REQUEST ROUTER

    - POST/request/send/interested/:userId
    - POST/request/send/ignored/:usedId
    - POST/request/review/:reqId
    - POST/request/rejected/:reqId

## USER ROUTER
